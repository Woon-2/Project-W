# Bundled fonts

게임과 함께 배포할 폰트 파일(`.ttf`, `.otf`, `.ttc`)을 이 폴더에 둡니다.

클라이언트는 시작할 때 이 폴더의 폰트를 DirectWrite 전용 컬렉션으로 읽습니다. UI가 요청한 폰트가 사용자 PC에 설치되어 있으면 시스템 폰트를 우선 사용하고, 설치되어 있지 않으면 이 폴더에서 같은 **내부 폰트 패밀리명**을 가진 폰트를 사용합니다.

넥슨 Lv2 고딕 파일을 추가할 때 파일명은 자유롭지만, 폰트 내부 패밀리명이 코드에서 사용하는 `넥슨Lv2고딕`과 일치해야 합니다. 폰트 배포 라이선스 파일도 함께 포함해 주세요.
